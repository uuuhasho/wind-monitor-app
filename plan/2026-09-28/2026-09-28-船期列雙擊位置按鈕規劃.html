02 · 行為規格

按鈕出現與點擊的規則

1

雙擊／快速點兩下只顯示按鈕

手機用兩次點擊偵測；桌面可用相同兩次點擊行為。第一次點擊不做複製、不跳轉。建議只保留一列按鈕；點另一列時切換到該列。

2

明確按「位置」才執行副作用

從該列讀取原始船名、去除前後空白，呼叫剪貼簿寫入；確認成功後，在同一分頁開啟 MarineTraffic。按鈕事件不得再觸發列的雙擊偵測。

3

剪貼簿被拒絕時不要假裝成功

若瀏覽器拒絕複製，留在 APP 顯示「複製失敗，點此重試」或可手動複製的船名；重試成功才跳轉。剪貼簿 API 需 HTTPS，並受瀏覽器權限與使用者操作情境影響。

鍵盤替代操作：提供可聚焦的船列與按鈕；鍵盤使用者可先聚焦目標列並按 Enter 顯示按鈕，再以 Enter 啟動「位置」。

03 · 網站跳轉

MarineTraffic 主用，VesselFinder 備用

MarineTraffic｜主用

官方說明確認可在 Live Map 搜尋列輸入船名、IMO 或 MMSI，並從結果點選船舶；目前尚未確認一個穩定、官方文件支持的船名直達搜尋 URL。

第一版：複製成功後開啟 MarineTraffic Live Map／搜尋入口，使用者人工貼上船名、確認結果。

VesselFinder｜備用

已驗證帶 `?name=` 參數的 vessels 頁會顯示船名搜尋結果。船名可能重複，仍需人工辨認目標。

備用連結：https://www.vesselfinder.com/vessels?name={URL-encoded ship name}

MarineTraffic 自動帶入搜尋的驗證邊界

可先人工探索網站正常搜尋所產生的公開網址，並測試登入、手機瀏覽器及重新整理後是否穩定；若確認網址格式穩定，再列為直達搜尋候選。此計畫不會透過程式填寫對方網站的輸入框、不讀取其頁面資料，也不使用隱藏自動操作。

04 · 範圍與界線

這次功能做什麼、不做什麼

納入

測試版 PWA 船列雙擊顯示按鈕、按鈕點擊才複製、開啟外站、複製失敗提示、手機與桌面驗收。

不納入

自動登入／自動輸入或提交搜尋、解析網頁座標、AIS API、位置資料儲存／地圖、正式版同步，以及任何 Cloud Run／Artifact Registry 變更。

預計主要檔案：`奶昔APP/public/index.html`（Firebase Hosting 實際發布來源）。實作前先確認是否另有原始 HTML 需同步；本階段不改動其他版本或部署。

主要驗收項目
情境預期結果

雙擊一列只在該列船名右側顯示綠底白字「位置」。
