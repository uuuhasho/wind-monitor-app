# Manual Acceptance Steps · 001-pwa-ui-redesign

請在實際手機或本機瀏覽器開啟 `public/index.html`（若未授權部署正式環境，可於本機預覽伺服器驗證），完成以下 4 步主要操作確認：

1. **主畫面風格、頂部功能與風速狀態判讀**
   - 開啟首頁，確認整體為淺灰底＋滿版白卡片風格、無毛玻璃特效；頁籤標題顯示 `臺中LNG船監控(v1.5)`。
   - 確認頂部左側顯示 `logo.png` + `臺中LNG船監控`；右側顯示「操作說明 `i` 圓形圖示」（可連至 `presentation/index.html`），且有船監控時左側出現鈴鐺圖示（預設靜音、可進港點擊開啟變亮橘色、再點靜音）。
   - 確認「北堤風速」卡片內風圖示位於 `m/s` 上方、無 `風速預報` 按鈕，且狀態膠囊顯示於風速右側（綠底 `可進港 •` / 紅底雙行 `無法進港 •` + `風速超標` 或 `浪高`/`能見度`；抓到 POB 後狀態消失、出現 POB Record 卡）。
2. **船期表與底部 4 鍵導覽列**
   - 確認「船期表」三欄為 `日期`（下方膠囊 `W12` 橘色 / `W13` 深藍）、`船名`、`速限 m/s`（僅顯示數字）；雙擊表頭不再觸發調整彈窗。
   - 依序點擊底部 4 鍵：`監控`（回主頁）、`預報`（開啟原深色天氣預報圖表，且點風速數字亦可開）、`船期`（跳出密碼驗證）、`聊天室`（開啟原 v2 聊天室，未讀紅點顯示於此鍵）。
3. **手動監控設定底部抽屜**
   - 點擊「船期表」右上角齒輪（游標滑過會旋轉）並完成密碼驗證。
   - 確認自螢幕底部滑出抽屜：未監控時可使用 `12.0 m/s` / `15.0 m/s` / `自訂` 與 `W12` / `W13` 分段按鈕切換；監控中時顯示目前監控船舶摘要、POB / 無法進港原因與紅色「結束監控」按鈕。
4. **船期調整雙行卡片與刪除功能**
   - 從底部導覽「船期」驗證密碼進入「船期調整」全螢幕清單，確認每筆船期皆為雙行卡片（第一行：日期 + W12/W13 下拉 + 紅色垃圾桶刪除鍵；第二行：船名 + 12/15 速限下拉）。
   - 試點右上角 `＋ 新增`、輸入 `MM/DD` 或 4 位數字日期、點刪除鍵確認移除，並確認有「未進港待排期」船隻時會置頂顯示空白日期列；按「儲存調整」送出（若在離線或未授權上線前，僅觀察前端格式檢核與送出提示）。
