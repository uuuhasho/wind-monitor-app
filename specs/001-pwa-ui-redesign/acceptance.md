# Manual Acceptance Steps · 001-pwa-ui-redesign

請在實際手機或本機瀏覽器開啟 `public/index.html`（若未授權部署正式環境，可於本機預覽伺服器驗證），完成以下 4 步主要操作確認：

1. **主畫面配色、頂部功能與風速狀態判讀**
   - 開啟首頁，確認整體採用「港務藍灰金」配色（冷霧灰底 `#E9EEF4`＋純白卡片＋滿版深海軍藍頂部條與琥珀金底邊），頁籤標題顯示 `臺中LNG船監控(v1.5)`。
   - 確認頂部左側顯示圓白徽章 `logo.png` + 白色 `臺中LNG船監控`；右側僅顯示「操作說明 `i` 圓形圖示」（可連至 `presentation/index.html`），已移除右上角鈴鐺。
   - 確認「北堤風速」標題字體放大加粗，且**更新時間位於風速數字下方**；**未監控／已完成時風速數字與時間置中對齊**（無右側大片空白），有船監控時自動左右分割於右側顯示狀態膠囊與靠左時間（綠底 `可進港 •` / 紅底雙行 `無法進港 •`；抓到 POB 後狀態消失、出現 POB Record 卡）。
2. **船期表、鈴鐺回歸與底部 4 鍵導覽列**
   - 確認「船期表」表頭呈現**霧藍灰底色 (`#DCE5F0`)**，三欄為 `日期`（下方膠囊 `W12` / `W13`）、`船名`、`速限 m/s`（僅顯示數字）；**監控中時提醒鈴鐺回歸標題列中央**（位於「船期表」與齒輪之間，預設靜音、可進港點選亮橘色、再點靜音）；雙擊表頭不再觸發調整彈窗。
   - 依序點擊底部 4 鍵：`監控`（維持乾淨深藍無黃色標記回主頁）、`預報`（開啟原深色天氣預報圖表，選中亮起琥珀金膠囊；點風速數字亦可開）、`船期`（跳出密碼驗證，選中亮起琥珀金膠囊）、`聊天室`（開啟原 v2 聊天室，未讀紅點顯示於此鍵）。
3. **手動監控設定底部抽屜**
   - 點擊「船期表」右上角齒輪（游標滑過會旋轉）並完成密碼驗證。
   - 確認自螢幕底部滑出抽屜：未監控時限制風速僅保留 `12` / `15`（無 `m/s` 與「自訂」），可切換 `W12` / `W13`；監控中時顯示目前監控船舶摘要、POB / 無法進港原因與紅色「結束監控」按鈕。
4. **船期調整雙行卡片、按鈕細節與對齊**
   - 從底部導覽「船期」驗證密碼進入「船期調整」全螢幕清單，確認**左上角只留向左箭頭**（無「監控」二字）、**右上角為圓形 `+` 按鈕且游標滑過會旋轉並變綠**、**上下固定欄與中間卡片左右切齊一致**。
   - 確認每筆船期皆為雙行卡片（第一行：日期 + W12/W13 下拉 + 紅色垃圾桶刪除鍵；第二行：船名 + 12/15 速限下拉），測試新增、輸入 `MM/DD` 或 4 位數日期、刪除確認，並確認有「未進港待排期」時置頂顯示。
