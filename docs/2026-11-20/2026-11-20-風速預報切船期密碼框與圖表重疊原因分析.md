# 2026-11-20 風速預報切船期密碼框與圖表重疊原因分析

## 1. 錯誤現象
於 `風速預報` 分頁（`#forecastModal`）顯示曲線圖 Tooltip（`.custom-tooltip`）時，點擊底部導覽列「船期」（`#navScheduleBtn`）開啟安全驗證密碼視窗 `#pwdModal`，ECharts Tooltip 懸浮卡片會直接穿透並蓋在白色 `#pwdModal` 輸入對話框左側上方，遮擋「安全驗證 / 請輸入密碼」標題與輸入框，無法正常輸入密碼（如使用者回報截圖 `C:\Users\hilla\Desktop\003.png`）。

## 2. 根因分析
1. **ECharts Tooltip 高層級預設**：ECharts v5.5.0 渲染 DOM Tooltip（`.custom-tooltip`）時，會在容器內建立帶有極大 inline `z-index: 9999999` 的定位節點；且切換至 `船期` 點擊 `#navScheduleBtn` 時，`triggerOpenScheduleAdjustModal()` 先開啟 `#pwdModal`（`z-index: 2000`），此時尚未通過密碼驗證，背景分頁仍維持在顯示中的 `#forecastModal`。
2. **缺少獨立層疊上下文（Stacking Context）**：修改前 `.forecast-chart-card` 未設定 `position` / `z-index` / `isolation`，`.chart-wrapper` 雖有 `position: relative` 但未設定 `z-index` 與 `isolation: isolate`，導致內部的 `.custom-tooltip`（`z-index: 9999999`）直接參與頂層根文件層疊比較，壓過 `#pwdModal`（`z-index: 2000`）與底/頂導覽列（`z-index: 950`）。
3. **解法**：於 `.forecast-chart-card` 與 `.chart-wrapper` 同時建立 `position: relative; z-index: 1; isolation: isolate;`，將 `#forecastChart` 及其 Tooltip 的 `z-index: 9999999` 嚴格鎖在 `z-index: 1` 的區域層疊上下文內。Tooltip 仍高於圖表畫布與 `dataZoom` 滑動條，但無法突破外層覆蓋 `z-index: 2000` 的 `#pwdModal`。
