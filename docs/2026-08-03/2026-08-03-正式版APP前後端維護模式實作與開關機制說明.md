# 2026-08-03 正式版 APP 前後端維護模式實作與開關機制說明

## 1. 需求與現象說明
因應例行保養或系統維護需求，正式版 APP (GitHub Pages + GAS Web App + Firebase Realtime Database) 需要提供一套可隨時「暫時關閉 (前後端同步暫停)」與「一鍵復原」的控制機制。
同時要求：
1. APP 畫面上不增加任何額外按鈕/選單，維持 100% 純淨。
2. 關閉時前端呈現美麗尊榮的「🛠️ 系統例行維護中」卡片遮罩。
3. 後端 GAS 背景任務與 LINE 告警通知同步暫停。
4. 復原時瞬間一鍵恢復正常監控畫面與後端運作。

---

## 2. 根因分析與機制設計 (管道 1: Milkshake-monitor)

本機制採用 **管道 1 (Firebase Console 控制台網頁開關)** 進行實施：

* **控制台專案名稱**：[Firebase Console (Milkshake-monitor)](https://console.firebase.google.com/)
* **Realtime Database 網址**：`https://milkshake-monitor-default-rtdb.asia-southeast1.firebasedatabase.app/`
* **資料節點**：`/system_status/maintenance` (Boolean: `true` / `false`)

### 運作原理：
1. **前端 UI**：`index.html` 靜默綁定 `db.ref('system_status/maintenance').on('value', ...)`。當為 `true` 時彈出 `#system-maintenance-overlay` 全螢幕高感度玻璃擬物防護牆；當為 `false` 時遮罩自動隱藏。原本的 `index.html` 代碼完好保留，僅暫時 off 介面與點擊。
2. **後端排程**：`gs_NV4.7.7.js` 新增 `isSystemInMaintenance()`。在 `doPost()` (LINE Webhook)、`checkDailySchedule()` (04:00 每日船期排程) 與 `executeMonitor()` (每分鐘風速採樣) 頂層加入攔截，當維護模式為 `true` 時自動返回 (Early Return)，停止背景資料寫入與 LINE 訊息發送。

### 後端：`正式版/gs_NV4.7.7.js`
```diff
+ // --- 系統維護模式防護閘門 (管道 1: Milkshake-monitor system_status/maintenance) ---
+ function isSystemInMaintenance() {
+   try {
+     const res = callFirebase("system_status/maintenance", null, "get");
+     const text = res ? res.getContentText() : "false";
+     return safeJsonParse(text) === true;
+   } catch (e) {
+     console.error(`維護模式檢查失敗: ${e.message}`);
+     return false;
+   }
+ }

  function doPost(e) {
+   if (isSystemInMaintenance()) {
+     console.log("🚧 正式版系統處於維護模式，暫停 Webhook 處理。");
+     return ContentService.createTextOutput("MAINTENANCE").setMimeType(ContentService.MimeType.TEXT);
+   }

  function checkDailySchedule() {
+   if (isSystemInMaintenance()) {
+     console.log("🚧 正式版系統處於維護模式，暫停 checkDailySchedule。");
+     return;
+   }

  function executeMonitor() {
+   if (isSystemInMaintenance()) {
+     return;
+   }
```

## 5. 管理者一鍵維護操作指南 (SOP)

- **🛑 關閉 APP (顯示維護中 & 暫停後端)**：
  1. 開啟 [Firebase Console](https://console.firebase.google.com/) ➔ 選擇專案 **Milkshake-monitor** ➔ **Realtime Database**。
  2. 尋找 `/system_status/maintenance` 節點，將數值設為 `true`。

- **🟢 復原 APP (恢復正常存取 & 開啟後端)**：
  1. 開啟 Firebase Console。
  2. 將 `/system_status/maintenance` 改回 `false` 即可。
