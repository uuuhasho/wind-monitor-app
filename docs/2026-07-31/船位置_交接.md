## 1. 功能需求摘要 (What We're Building)

在「臺中 LNG 船監控」測試版 APP 中新增「船舶即時位置查詢與地圖視覺化」功能：

- 使用者在 APP 船期表（`.schedule-table`）對目標船隻列**向右滑動 (Swipe Right)**
- 從螢幕右側滑入一個 **100% 寬度的全螢幕 Drawer 視窗**
- Drawer 內嵌 **VesselFinder aismap iframe**（免費、0 後端負擔）
- 顯示船舶的**位置、船名、最後更新時間（台灣時間 UTC+8）**
- 地圖支援**雙指縮放 (Pinch-to-Zoom)** 與**單指拖曳平移**
- **費用完全為 0**

## 6. 技術限制與防呆提醒 (Constraints Reminder)

> [!CAUTION]
> - **GCP 容器 <500MB**：嚴禁安裝 Playwright / Selenium / Chrome
> - **測試版 Firebase**：專案 ID `newlngship`，所有路徑帶 `test/` 前綴
> - **Secret Manager BOM 防護**：讀取環境變數必須 `.strip().strip("\ufeff")`
> - **HTTP 方法大寫**：GAS `UrlFetchApp` 的 method 必須 `.toUpperCase()`
> - **多層級目錄同步**：若修改 `測試版/src/` 下的 Python 模組，根目錄 `src/` 也需同步
> - **LNG 船夜航限制**：POB 時間只會落在 04:00~17:00
