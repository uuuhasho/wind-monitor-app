# 補齊 GAS 日曆觸發器

## 現象與根因

使用者確認線上共有四個觸發器，但原 `setupSystemTriggers()` 先刪除目前帳號的專案觸發器，只重建三個時間觸發器，會漏掉 `onCalendarOrSheetChange`。

## 變更

- 以函式名稱及觸發來源判斷既有觸發器，僅建立缺少項目，不刪除既有或不相關的觸發器。
- 日曆觸發器另比對來源 ID：`89f17p8et94udnavnaqgihrgvg@group.calendar.google.com`。
- 三個時間觸發器缺少時，沿用原設定建立：每日 04 時、每分鐘、每日 23 時。

核心 diff：

```diff
- triggers.forEach(t => ScriptApp.deleteTrigger(t));
+ const hasTrigger = (handler, source, sourceId = null) => triggers.some(/* 比對函式、來源與指定日曆 */);
+ if (!hasTrigger("onCalendarOrSheetChange", ScriptApp.TriggerSource.CALENDAR, calendarId)) {
+   ScriptApp.newTrigger("onCalendarOrSheetChange").forUserCalendar(calendarId).onEventUpdated().create();
+ }
```

## 驗證與界線

`node tests/test_gas_triggers.js` 四個情境通過：空清單建立四項、重複執行不重複、只補缺少日曆項目、保留其他日曆及不相關觸發器。

`node tests/test_gas_archive.js` 21 個情境、Node 語法及差異檢查通過。所有服務皆為模擬，沒有部署或執行線上初始化。

既有時間觸發器的精確時分與間隔無法從 Trigger 物件讀取，本次保留使用者已確認的時程；初始化只針對執行帳號可列出的觸發器補缺。
