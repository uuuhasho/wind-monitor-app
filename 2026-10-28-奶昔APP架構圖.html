奶昔 APP 系統架構圖

臺中 LNG 船風速監控：前端直接讀取 Firebase 即時資料；Google Apps Script 負責監控與船期；Cloud Run 負責風速預報及 LINE 進港訊息解析。

系統總覽預報管線監控與歸檔資料來源
閱讀界線：這是依本機程式碼整理的架構，不代表線上部署一定與本機一致。RTDB /test 是 APP 使用中的資料，並非可任意清除的沙箱。

01｜系統總覽

使用者從 Hosting 開啟 APP。APP 直接讀取資料庫，也可呼叫 GAS 執行操作，或呼叫 Cloud Run 手動更新預報。

02｜預報資料如何進入 APP

Cloud Run 先取得工作鎖，再處理預報文件與圖片，整合 Open-Meteo 後發布至 RTDB；前端讀取預報資料與更新時間。

03｜即時監控、進港與歸檔

GAS 合併船期及人工調整、取得港務風速，更新 RTDB。進港後寫入 POB 資訊並嘗試接力下一艘船；夜間歸檔至試算表。
